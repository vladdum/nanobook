## Surprises

- `default_nettype none` rejected by Vivado for `input logic *_tready` ports (works in Verilator).
  Stripped from `type_dispatch.sv`; remaining modules already lacked it.
- Per-module `` `include `` directives collided with Vivado's glob-based file list, producing 5
  "overwriting previous definition" critical warnings. Resolution: keep only the
  `book_event_pkg.sv` include (guarded with `` `ifndef ``); let the synth tool resolve module
  references from the file list.
- OOC critical path measured ~1.76 ns regardless of the constraint, indicating combinational
  depth, not optimization headroom, sets the ceiling. 500 MHz OOC barely meets (WNS +0.236 ns)
  and would not survive PnR.
