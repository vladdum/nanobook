# M06 Retrospective

## What we shipped

- `hw/ip/lob_core/sym_idx_lut.sv` — combinational distRAM lookup from ITCH
  `stock_locate` → `{valid, sym_idx}`, init from
  `lob_core_sym_pkg::STOCK_LOCATE_TO_SYM_IDX` (auto-generated by Phase A from
  the 2019-03-27 top-100 selection). Replaces the M05 single-symbol
  `SYMBOL_FILTER_ID` comparator at the orchestrator entry. Unmapped events
  silently drop and bump `sym_lut_misses` (alongside the kept-for-compat
  `events_filtered`).
- `hw/ip/lob_core/per_sym_state.sv` — 128-entry distRAM regfile holding
  `{epoch[15:0], origin[31:0], midprice[31:0], rebase_count[15:0]}`
  per symbol. Two read ports (ADD path + d3 stale-check) + one write
  port (rebase or EMA). Reset initialises from
  `lob_core_sym_pkg::INITIAL_MIDPRICE` with `origin = midprice − 2048`
  (clamped at 0).
- `hw/ip/lob_core/tob_tracker.sv` D.1–D.3 — hierarchical level-1 (FF) +
  level-2 (URAM) bitmaps; 2-stage 64×64 pipelined CLZ replaces the M05 flat
  4096-bit priority encoder; CLZ-driven `pending_clr_*` emit path. Per-sym
  best registers indexed by `op_sym_idx` (currently tied off to 0 until
  Phase F+H thread sym_idx through the ladder ops).
- `hw/ip/lob_core/lob_core.sv` — `sym_idx_lut` instantiated at the input;
  `a1_pl_q.sym_idx` stamped from the LUT output; `per_sym_state`
  instantiated with two read ports; OOW-ADD rebase trigger writes pss
  (epoch++, rebase_count++, origin = price − WINDOW_HALF_TICKS) and
  bumps `rebases_total`; d3 stale-check uses pss read port 2.
- `dv/unit/lob_core/` — three new TBs and matching Makefiles:
  - `tb_sym_idx_lut.py` — 5 tests covering mapped / unmapped lookups and
    the combinational-no-clock contract.
  - `tb_per_sym_state.py` — 6 tests covering reset init, rebase + EMA
    writes, cross-sym isolation, 2-read-port independence, and consecutive
    rebases.
  - `tb_lob_core_cycles_m06.py` — 4 tests asserting M05 ADD = 4 cycle
    regression, DELETE-side-empty = 6 cycles, DELETE-CLZ = 12 cycles, and
    that the CLZ-vs-side-empty delta exactly matches `CLZ_LATENCY + 5`
    (the +5 is the fixed orchestrator overhead).
  - `tb_lob_core_rebase.py` — 3 tests covering OOW-ADD-driven rebase
    counter bump, end-to-end stale-DELETE silent drop, and per-sym
    isolation via the `epoch_reg` backdoor.
- `dv/unit/lob_core/tb_tob_tracker.py` — 2 new D.3 tests for the CLZ-driven
  emit path (bid + ask sides). `_reset()` now backdoor-zeros
  `slice_bitmap_ram` so cross-test residue cannot leak into a CLZ scan.
- `docs/design.md` §4.4 amended to refbook's drop-on-rebase semantics
  (epoch counter + inline-free); the M02 FROZEN CONTRACT supersedes the
  earlier "translate ticks to new offsets" draft.
- `dv/integration/m06_exit.sh` — partial exit gate (Verilator-only;
  see deferrals below).

The DELETE-CLZ "12 cycles" line: the plan's `7` came from a different
cycle-counting boundary (events_in vs m_tvalid). The m06 cycle TB
measures handshake → m_tvalid: M05 baseline was 5 cycles for the
side-empty path, the CLZ-driven follow-up adds 6 more = 11 — the
extra cycle comes from registering `m_tvalid_q` in the update_size
branch. The cross-check `test_clz_latency_extra_cycles_match_param`
asserts the delta == `CLZ_LATENCY + 5` so a future CLZ_LATENCY = 2
bump (Phase J fallback) trips it cleanly.

## Which risks fired

- **Cross-test URAM residue** (not in the spec risk list — a new one). The
  `slice_bitmap_ram` URAM has no synchronous reset (correct for silicon),
  but cocotb runs successive tests in one sim session without re-loading
  the binary. A previous test's set bits leaked into the next test's CLZ
  scan and produced wrong new-best ticks. Fix: `_reset()` backdoor-zeros
  the array.
- **m05_exit.sh inadvertent Vivado synth**: the gate's step [8] runs
  `make lob-core-synth`, which is fenced by the
  no-synthesis-without-permission preference. m06_exit.sh substitutes a
  Verilator-only subset and notes the deferral.

## Surprises

- The CLZ-driven emit path adds 6 cycles (not 5 as initially planned)
  between the clr cycle and the final m_tvalid — the extra cycle comes
  from the orchestrator's `update_size_req` registering `m_tvalid_q`
  in tob_tracker's update_size branch. The `_match_param` cross-check
  test bakes this in.
- `INITIAL_MIDPRICE` is sized to `N_SYMBOLS_USED` (= 100) in the package
  but per_sym_state needs `N_SYMBOLS` (= 128) entries. Resolved by
  taking the table length as a separate parameter and padding zero
  values internally for indices ≥ `N_SYMBOLS_USED`.
- Verilator's UNUSEDPARAM warning fires per-instance: every module
  that imports `lob_core_params_pkg` and doesn't touch every parameter
  needs the `_PKG_*` localparam-touch waiver pattern. Both `sym_idx_lut`
  and `per_sym_state` picked this up.

## F.2 full — what landed this session

- §1 `sym_idx` threading through ladder ops:
  `pending_clr_sym_idx_o` on tob_tracker, `level_evt_sym_idx` on
  price_ladder, muxed `ladder_op_sym_idx` and `tob_op_sym_idx`.
- §2 per-sym ladder origin: `price_ladder.addr_of` and the internal
  `in_window` check use `op_origin`, sourced from `pss_read_origin`
  (port 1 for ADD/read, port 2 for DEL). Added `read2_origin` to
  per_sym_state.
- §3 per-sym `ev_in_in_window` check using `pss_read_origin_w`.
- §4 squash-and-retry: `s_tready` deasserts on the rebase-trigger cycle
  (AXI-S holds the ADD) so the post-rebase re-presentation lands in the
  ladder. Cycle cost: 1 stall + 4 normal ADD cycles = 5 cycles to
  m_tvalid for a rebase-triggering ADD, asserted by
  `test_oow_add_triggers_rebase_and_completes`.
- §5 `pending_clr_sym_idx_o` (covered by §1).
- §6 per-sym `any_set` in tob_tracker's clr branch, replacing the
  global `any_set(bid/ask_bitmap_q)`. The global bitmaps remain as
  debug-only state under a UNUSEDSIGNAL waiver.
- §7 read-port-1 mux on rebase write was already in place from minimal
  F.2 (rebase write only on OOW ADD). Port-2 mux between d3 and
  clr_fu_sym_idx_q is the next-best concurrent-op fix — currently the
  cycle clr_fu1 fires uses port 2's d3 value; documented as best-effort
  in `lob_core.sv`.

`WINDOW_HALF_TICKS` is now derived as `WINDOW_SIZE_TICKS / 2` in
lob_core's `per_sym_state` instantiation and the rebase trigger math
(`EFFECTIVE_HALF_TICKS`). The package's static `WINDOW_HALF_TICKS=2048`
is effectively unused. Without this fix the smoke / cycles TB
overrides (WINDOW_SIZE_TICKS=64) would put the rebased origin too far
from the trigger price.
