# M1 Retrospective

## What took longer than planned

- Vivado IP regen and GTY wrapper port required careful verification of PG195/PG276/UG1280
  pin and port names — not yet benchmarked against original estimates (fill after hardware run).
- Shell bitstream timing closure: TBD (first build not yet run).

## Which risks fired

- **GTY wrapper port:** Corundum U50 fpga_100g reference had no version tags at pin time;
  pinned to specific commit SHAs instead.
- **HBM IP port names:** Must be verified against generated `.veo` stub before first synth.
- **XDMA IP ports:** Must be verified against PG195 generated example before first synth.

## Surprises

- Neither `verilog-ethernet` nor `corundum` upstream repos have semantic version tags.
  Pinned to specific SHA commits; documented in `third_party/README.md`.
- Vivado in-process (`-in_memory`) flow chosen over `launch_runs` to avoid batch-mode hangs.

## Amendments

- BAR0 register map implemented per `docs/design.md` §5.1 (CONTROL at 0x10, STATUS at 0x14).
  Plan Task 6 draft had incorrect offsets (0x08/0x0C); corrected during implementation.
- CONTROL[6:3] used for diagnostic gpio_led_ctrl (not formally in spec; to be spec-amended or
  removed before M2 if not needed).
- HBM smoke test trigger added as CONTROL bit 4 + STATUS bits [9:8]; spec amendment needed
  before BAR0 freeze is final.
