# M01 Retrospective

## What we shipped

- `nanobook_shell_top.bit` — 55 MB Vivado 2025.2 bitstream for `xcu50-fsvh2104-2-e`
- BAR0 register file (ID, VERSION, CONTROL, STATUS, GIT\_SHA\_LO/HI) with AXI-Lite slave
- HBM wrapper: 16 MB (AXI\_00) smoke test, APB init, all 32 port tie-offs
- 10G GTY wrapper: single-lane 10G-BASE-R over QSFP28 lane 0, XGMII loopback
- XDMA 4.2 wrapper: PCIe x4, IBUFDS\_GTE4, IBUFDS for HBM refclk, Corundum PHY IBUFDS\_GTE4
- Vivado in-process batch flow (`synth.tcl`): synth → opt → place → route → bitstream

## What took longer than planned

**Seven synthesis/implementation iterations** were required to produce a clean bitstream.
Build turnaround was ~2 hours per attempt; total wall time across all attempts was ~14 hours.

Each failure and its root cause:

| Build | Stage | Error | Root cause |
| --- | --- | --- | --- |
| 1–2 | opt | `[Opt 31-67]` LUT2 missing I0 | XDMA `m_axi_*` slave inputs undriven; `m_axil_rresp` wire undriven |
| 3 | opt | `[Opt 31-67]` LUT2 missing I0 in HBM IP | HBM IP requires all 32 AXI port `ACLK` driven; needs external IBUFDS; needs APB ports |
| 4 | synth | `get_name` not a valid Vivado command | Typo in `synth.tcl` debug-hub hook |
| 5 | route | `[Route 35-7]` 1 unroutable pin | PCIe refclk at wrong package ball (AM11); all GT pins using `PACKAGE_PIN` instead of `LOC`; missing IBUFDS\_GTE4 LOC |
| 6 | synth | `CRITICAL WARNING: not a valid site or package pin name` | Most XDC pin names invalid: AT30, BJ43, BC24, BE14, etc. |
| 7 | write\_bitstream | `[DRC PPURQ-1]` CATTRIP pin undriven | U50 board safety: `hbm_cattrip` (J18) must be driven or card RMAs |

Build 7 routed successfully; bitstream was produced via a Vivado ECO patch on the post-route checkpoint
rather than a full rebuild (saved ~2 hours).

## Which risks fired

**U50 board topology diverged from assumptions in several ways:**

- **QSFP management signals not FPGA I/O.** `qsfp0_modsell/resetl/modprsl/intl/lpmode` were wired as
  top-level ports. On U50 these signals route via the satellite controller (MSP430/CMS), not directly to
  FPGA I/O. Ports removed; management is out-of-band.
- **Only 3 physical LEDs.** `gpio_led[3:0]` assumed 4 LEDs. U50 exposes 3: `E18` (act), `E16` (stat\_g),
  `F17` (stat\_y). Port reduced to `[2:0]`.
- **HBM reference clock is the 100 MHz board oscillator.** A dedicated `hbm_refclk_p/n` differential pair
  was assumed; the correct source is `BB18/BC18` (LVDS, 100 MHz), used by Corundum as `clk_100mhz_1`.
  The port name was kept; only the XDC assignment changed.
- **`hbm_cattrip` (J18) is a board safety requirement.** Vivado DRC PPURQ-1 blocks bitstream generation if
  J18 is not driven. Driving it high signals over-temperature and forces a card power-off; must be held low.
- **IBUFDS\_GTE4 auto-placement.** Vivado places the IBUFDS\_GTE4 from the refclk port LOC automatically —
  no separate cell LOC constraint is needed or valid (site name `IBUFDS_GTE4_X1Y3` is rejected).
- **GT pin constraints require `LOC`, not `PACKAGE_PIN`.** GT sites do not have PACKAGE\_PIN entries in the device database.

**NASDAQ ITCH pcap acquisition deferred.** The data.nasdaq.com subscription is Core US Fundamentals,
not TotalView-ITCH raw feed. The `fetch.sh` script and pcap targets remain in the Makefile but are
no-ops until a suitable data source is found. Exit gate criterion "verify pcap SHA-256 checksums"
is carried to M02.

**On-hardware tests deferred.** No physical Alveo U50 is available. `make hbm-smoke` and
`make 10g-loopback` remain in the Makefile; the `dv/integration/m01_exit.sh` criteria for these
are carried to the first month hardware access is available.

## Surprises

- **XDMA 4.2 exposes a full AXI4 DMA master (`m_axi_*`) in addition to AXI-Lite (`m_axil_*`).**
  The DMA master has ~20 ports whose slave-side inputs must all be tied off to prevent dangling LUT
  inputs in opt. The PG195 veo stub makes this easy to miss.
- **HBM IP PG276 requires APB connections for initialization** even when APB is not used for register
  access. Leaving APB floating causes the IP's internal LUT to lose its driver in opt.
- **Corundum's `eth_xcvr_phy_10g_gty_wrapper` expects a buffered GT refclk**, not the raw differential
  port. An explicit `IBUFDS_GTE4` must be instantiated upstream. The Corundum XDC uses `LOC` format
  for refclk ports — Vivado does NOT automatically infer `IBUFDS_GTE4` when a differential top-level
  port is connected indirectly through the module hierarchy.
- **The Vivado ECO flow** (`open_checkpoint` + `create_cell/create_port/place_ports/route_design`) is
  viable for single-pin post-route fixes, saving significant rebuild time.

## Amendments to the design spec

These changes to `docs/design.md` were made during M01 implementation and are captured here for audit:

### BAR0 CONTROL register — additional bits

The spec had CONTROL as `[0]=enable, [1]=reset, [2]=pause`. Implementation added:

| Bit | Name | Description |
| --- | --- | --- |
| `[2:0]` | `PIPELINE_CTRL` | Enable / reset / pause (as spec) |
| `[3]` | `LED0` | GPIO LED 0 (diagnostic) |
| `[4]` | `HBM\_SMOKE\_GO / LED1` | Triggers HBM 16 MB smoke test; doubles as LED1 |
| `[5]` | `LED2` | GPIO LED 2 (diagnostic) |
| `[6]` | `LED3` | GPIO LED 3 (diagnostic; no physical LED — bit silently dropped) |

The dual use of bit 4 (smoke trigger + LED) is intentional for diagnostic visibility.
CONTROL[6:3] → `gpio_led_o[3:0]`; only `[2:0]` reach physical pins post-M01.

### BAR0 STATUS register — bit assignments

The spec left STATUS undetailed. Implemented layout:

| Bit | Name | Description |
| --- | --- | --- |
| `[0]` | `HBM_READY` | HBM IP APB init complete |
| `[1]` | `ETH10G_READY` | 10G PHY `rx_block_lock` asserted |
| `[7:2]` | — | Reserved, read as 0 |
| `[8]` | `HBM_SMOKE_DONE` | Smoke test completed |
| `[9]` | `HBM_SMOKE_ERR` | Smoke test detected any error |
| `[31:10]` | — | Reserved, read as 0 |

Both STATUS extensions (HBM\_SMOKE\_DONE/ERR) are not in `docs/design.md §5.1`; a spec PR is needed
before BAR0 freeze is considered final per the Cross-Month Interface Freeze List.
